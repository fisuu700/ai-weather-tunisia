# 🌤️ Plateforme d'intelligence météorologique par Machine Learning & IA Tunisienne 🇹🇳

Prédiction multi-jours (1 à 7 jours) de la température, risque de pluie, vent, humidité et pression pour les **24 gouvernorats de la Tunisie**.

## Fonctionnalités
- 🔮 **Prévisions ML** : RandomForest, Gradient Boosting, XGBoost avec intervalles de confiance IC 90%
- 💬 **Chatbot IA 100% Tounsi** : Comprend le dialecte tunisien (Derja & Arabizi) et répond avec les vraies données météo
- 🗺️ **Carte interactive** : Carte Folium avec les 24 gouvernorats
- 🛰️ **Données temps réel** : Open-Meteo (conditions actuelles + prévisions horaires)
- 🧠 **Explicabilité SHAP (XAI)** : Comprendre les prédictions des modèles ML
- 🌦️ **Climatologie** : Normales, anomalies et tendances de réchauffement

## Gouvernorats supportés
Grand Tunis (Tunis, Ariana, Ben Arous, Manouba) · Nord (Bizerte, Nabeul, Zaghouan, Béja, Jendouba, Le Kef, Siliana) · Centre (Sousse, Monastir, Mahdia, Sfax, Kairouan, Kasserine, Sidi Bouzid) · Sud (Gabès, Médenine, Tataouine, Gafsa, Tozeur, Kébili)

## Stack Technique
Python · Streamlit · scikit-learn · XGBoost · SHAP · Plotly · Folium · Open-Meteo · Meteostat
